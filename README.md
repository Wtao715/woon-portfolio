# Woon Wen Tao — Developer Portfolio

A responsive, light-theme developer portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Internet is only needed for the optional Google Fonts; the site content and local artwork are stored in this folder.

## Personalise before publishing
- Add your portrait as `assets/images/profile-photo.jpg` (recommended: portrait crop, JPG or PNG renamed to `.jpg`). The site uses a placeholder illustration until this file exists.
- Check `assets/Woon_Wen_Tao_Resume.pdf` and replace it with your latest resume if needed.
- Review the project descriptions and ensure every statement matches what you personally implemented.
- Add any public project repository or demo links only if you are authorised to share them.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `woon-portfolio`.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. In repository Settings → Pages, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Open the published URL shown in GitHub Pages settings.

## Notes
- The internship project is intentionally described at a high level. Do not upload company source code, private screenshots, customer information or credentials.
- The VeriqURL description is framed as a prototype decision-support tool, not a guarantee of URL safety.
